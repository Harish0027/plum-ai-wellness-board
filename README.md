# 💡 AI Tips App

This is a **Next.js 14 project** that allows users to view, save, and manage AI-generated tips.  
It uses **Google Gemini API** for AI responses and **Redis** for caching saved tips.  

Bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

---

## 🚀 Features
- ✅ AI-powered tips using Google Gemini API  
- ✅ Save & retrieve tips with Redis  
- ✅ Responsive UI with TailwindCSS + ShadCN UI  
- ✅ LocalStorage integration for offline saves  
- ✅ Deployable on Vercel with environment variables  

---

## 📦 Tech Stack
- [Next.js 14](https://nextjs.org/)  
- [TypeScript](https://www.typescriptlang.org/)  
- [TailwindCSS](https://tailwindcss.com/)  
- [ShadCN UI](https://ui.shadcn.com/)  
- [Google Gemini API](https://ai.google.dev/)  
- [Redis](https://redis.io/)

## ⚙️ Setup Instructions

### 🔹 Step 1 — clone the repo
```bash
git clone https://github.com/Harish0027/plum-ai-wellness-board
cd plum-ai-wellness-board
```

### 🔹 Step 2 — Install dependencies
```bash
npm install
```


### 🔹 Step 3 — run command
```bash
npm run dev
```
